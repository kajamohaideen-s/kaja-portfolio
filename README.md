# Kaja Mohaideen — Portfolio Website

A responsive, colourful and professional portfolio website built from the information in the supplied resume and profile photo.

## Included
- `index.html` — portfolio structure/content
- `styles.css` — responsive dark gradient design
- `script.js` — mobile menu + scroll reveal
- `assets/profile.jpg` — supplied profile photo
- `assets/resume.pdf` — supplied resume

## Run locally
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in a browser.
4. For the best development experience, use the VS Code Live Server extension.

## Important: add your real links
The portfolio intentionally uses placeholders for LinkedIn and GitHub because the supplied resume only listed the words “LinkedIn” and “GitHub”, not the actual URLs.

Search `index.html` for:
- `showLinkNotice('LinkedIn')`
- `showLinkNotice('GitHub')`
- `showLinkNotice('GitHub')` in the project button

Replace those placeholder links with your real LinkedIn profile and GitHub repository/profile URLs.

## Deployment
You can deploy this static site using GitHub Pages, Netlify, Vercel, or another static hosting provider.
